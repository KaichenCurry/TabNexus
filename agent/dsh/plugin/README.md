# dsh-plugin-tabnexus

TabNexus for DSH：把浏览器里散落的任务上下文，变成 Harness 可直接调用的插件化记忆。

- host 面：注册 17 个 `mcp__tabnexus__*` 工具 + 面板数据路由（workspace/action/status）
- client 面：DSH 浏览器工作区面板（任务/章节/页面/状态/移动/收件口）

安装与使用教程见仓库 [agent/dsh/README.md](https://github.com/KaichenCurry/TabNexus/tree/main/agent/dsh#readme) 与 [docs/INSTALL_DSH.md](https://github.com/KaichenCurry/TabNexus/blob/main/docs/INSTALL_DSH.md)。

前置：Chrome 加载 TabNexus 扩展并启用「本机 Agent 连接」；Node ≥ 22.13。
